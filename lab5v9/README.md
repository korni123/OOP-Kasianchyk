# Лабораторна робота №5

**Тема:** Поліморфізм: динамічне зв'язування та перевизначення методів.

**Варіант:** 9 — поліморфні інструменти `Tool → Hammer, Screwdriver, Wrench`

## Опис ієрархії класів

### Tool (базовий клас)

- **Поле:** `name` (string) — приватне
- **Властивість:** `Name`
- **Конструктор:** `Tool(string name)`
- **Віртуальний метод:** `virtual void Use()` — загальне використання інструмента

### Hammer (похідний від Tool)

- **Поле:** `weight` (double), **властивість:** `Weight`
- **Конструктор:** `Hammer(string name, double weight) : base(name)`
- **Перевизначення:** `override void Use()` — забиває цвях

### Screwdriver (похідний від Tool)

- **Поле:** `tipType` (string), **властивість:** `TipType`
- **Конструктор:** `Screwdriver(string name, string tipType) : base(name)`
- **Перевизначення:** `override void Use()` — закручує гвинт

### Wrench (похідний від Tool)

- **Поле:** `size` (int), **властивість:** `Size`
- **Конструктор:** `Wrench(string name, int size) : base(name)`
- **Перевизначення:** `override void Use()` — затягує гайку

## Демонстрація в Main

1. **Колекція базового типу** — створено `List<Tool>`, до неї додано об'єкти `Hammer`, `Screwdriver`, `Wrench`
2. **Поліморфізм** — у циклі `foreach` для кожного елемента викликається `Use()`, і завдяки динамічному зв'язуванню спрацьовує реалізація фактичного типу об'єкта
3. **Агрегація** — під час проходу по колекції назва і тип кожного інструмента додаються до списку `used`, після чого виводиться підсумковий список використаних інструментів та їх кількість
