# Лабораторна робота №3

**Тема:** Життєвий цикл об'єкта та керування ресурсами.

**Варіант:** 9 — клас `WebSocketClient`

## Опис класу

Реалізовано клас `WebSocketClient`, що впроваджує інтерфейс `IDisposable` та повний патерн Dispose:
- **Поля:** `_serverUrl` (string), `_isConnected` (bool) — імітує некерований ресурс (WebSocket-з'єднання)
- **Властивості:** `ServerUrl`, `IsConnected` (тільки для читання)
- **Конструктор:** "відкриває" з'єднання (`_isConnected = true`)
- **Метод:** `SendMessage(string message)` — надсилає повідомлення, якщо з'єднання активне
- **Dispose(bool disposing):** захищений віртуальний метод — звільняє керовані ресурси (якщо `disposing == true`) і завжди звільняє некерований ресурс (закриває з'єднання)
- **Dispose():** публічний метод — викликає `Dispose(true)` та `GC.SuppressFinalize(this)`
- **Деструктор `~WebSocketClient()`:** викликає `Dispose(false)` як резервний механізм звільнення ресурсу

## Три сценарії в Main

1. **using** — `Dispose()` викликається автоматично після виходу з блоку
2. **явний виклик Dispose()** — ресурс звільняється вручну одразу після використання
3. **без виклику Dispose()** — об'єкт залишається без явного звільнення, ресурс звільняється лише через фіналізатор при спрацюванні `GC.Collect()`
