# Лабораторна робота №4

**Тема:** Наслідування. Ключові слова `base`, `override`, `virtual`. Приховування членів (`new`).

**Варіант:** 9 — ієрархія `Weapon → Sword → Bow`

## Опис ієрархії класів

### Weapon (базовий клас)

- **Поля:** `name` (string), `damage` (int) — приватні
- **Властивості:** `Name`, `Damage` (читання і запис)
- **Конструктор:** `Weapon(string name, int damage)` — ініціалізує поля
- **Віртуальний метод:** `virtual void Attack()` — базова атака, виводить назву і шкоду
- **Звичайний метод:** `string GetWeaponType()` — повертає «Зброя (Weapon)», не віртуальний, тому може бути лише прихований через `new`

### Sword (похідний від Weapon)

- **Поле:** `material` (string), **властивість:** `Material`
- **Конструктор:** `Sword(string name, int damage, string material) : base(name, damage)` — назву і шкоду передає в конструктор базового класу
- **Перевизначення:** `override void Attack()` — рубаний удар мечем
- **Власний метод:** `Parry()` — парирування удару
- **Приховування:** `new string GetWeaponType()` — повертає «Меч (Sword)», приховує метод базового класу

### Bow (похідний від Weapon)

- **Поле:** `arrowType` (string), **властивість:** `ArrowType`
- **Конструктор:** `Bow(string name, int damage, string arrowType) : base(name, damage)`
- **Перевизначення:** `override void Attack()` — спочатку викликає `base.Attack()`, потім додає постріл стрілою
- **Власний метод:** `Aim()` — прицілювання

## Демонстрація в Main

1. **Власні методи** — виклик `Parry()` у меча та `Aim()` у лука
2. **Поліморфізм** — об'єкти `Weapon`, `Sword`, `Bow` зберігаються в масиві `Weapon[]`, виклик `Attack()` для кожного дає різний результат залежно від реального типу об'єкта
3. **override** — `Attack()` для того самого меча через посилання типу `Sword` і типу `Weapon` дає однаковий результат: метод обирається за типом об'єкта
4. **new** — `GetWeaponType()` для того самого меча через посилання типу `Sword` повертає «Меч», а через посилання типу `Weapon` — «Зброя»: метод обирається за типом посилання
5. **Властивості** — зміна шкоди меча через `Damage`
