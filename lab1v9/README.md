# Лабораторна робота №1

**Тема:** Створення першого проєкту. Класи, об'єкти, конструктори та деструктори.

**Варіант:** 9 — клас `Movie`

## Опис класу

Реалізовано клас `Movie` з такими елементами:
- **Приватні поля:** `title`, `genre`, `rating`
- **Публічна властивість:** `Rating` (з перевіркою діапазону 0–10)
- **Конструктор:** ініціалізує всі поля об'єкта
- **Деструктор:** виводить повідомлення при знищенні об'єкта
- **Метод:** `Play()` — виводить інформацію про фільм у консоль
