# Самостійна робота №9

**Тема:** Делегати й лямбда-вирази: власні утиліти для колекцій.

**Проєкт:** `lab9-self-v9`

## Опис класу

Реалізовано статичний клас `CollectionUtils` з узагальненими методами:
- **Map<TSource, TResult>** — перетворює кожен елемент через `Func<TSource, TResult>` (аналог `Select`)
- **MaxBy<T, TKey>** — повертає елемент з найбільшим ключем, `where TKey : IComparable<TKey>`
- **Filter<T>** — повертає елементи, що задовольняють `Predicate<T>` (аналог `Where`)
- **ForEach<T>** — виконує `Action<T>` для кожного елемента

## Демонстрація в Main

1. **List<Product>** — імена товарів, найдорожчий товар, товари дорожчі за 1000, вивід усіх
2. **List<int>** — квадрати, «парне/непарне», додатні числа, найбільше за модулем, сума через `ForEach`
3. **List<string>** — назви міст великими літерами, довжини, міста на «Л», найдовша назва
4. **Порівняння з LINQ** — результати `Map`, `Filter`, `MaxBy` збігаються з `Select`, `Where`, `MaxBy`
