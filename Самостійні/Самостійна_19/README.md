# Самостійна робота №19

**Тема:** Дизайн винятків і політики retry: теорія та кейси Polly.

Проєкт: `IndependentWork19`. Опис сценаріїв, обґрунтування стратегій і висновки — у файлі [REPORT.md](REPORT.md).

## Що в проєкті

- `InsufficientFundsException` — власний виняток з властивостями `RequestedAmount` і `CurrentBalance` та трьома стандартними конструкторами (без параметрів, з message, з message та innerException) і ще одним з даними про помилку
- `BankAccount` — рахунок з методом `Withdraw` (кидає виняток) і `TryWithdraw` (повертає `bool` та текст помилки)
- `DatabaseConnectionException` — виняток для помилки з'єднання з базою даних
- `Program.cs` — демонстрація винятку і три сценарії Polly:
  1. **Retry** з експоненційною затримкою і jitter — зовнішній API курсу валют
  2. **Circuit Breaker** — база даних, яка тимчасово не відповідає
  3. **Timeout + Fallback** — повільна черга повідомлень

Для кожної спроби і результату в консоль виводиться лог.

## Запуск

Бібліотека Polly підтягується автоматично з NuGet при першому запуску, потрібен інтернет.

```
cd Самостійні/Самостійна_19
dotnet run --project IndependentWork19
```

Програма працює близько 10 секунд, бо в сценаріях є затримки.
