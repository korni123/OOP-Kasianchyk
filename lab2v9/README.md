# Лабораторна робота №2

**Тема:** Клас із кількома конструкторами. Життєвий цикл об'єкта.

**Варіант:** 9 — клас `Movie`

## Опис класу

Реалізовано клас `Movie` з такими елементами:
- **Приватні поля:** `_title`, `_genre`, `_rating`
- **Властивості:** `Title`, `Genre`, `Rating` (з валідацією діапазону 0–10)
- **Конструктори:**
  - за замовчуванням `Movie()` — викликає параметризований через `: this("Untitled", "Unknown", 5.0)`
  - параметризований `Movie(string title, string genre, double rating)`
- **Деструктор:** виводить повідомлення при знищенні об'єкта
- **Метод:** `Play()` — виводить інформацію про фільм у консоль

## Висновок

У ході виконання лабораторної роботи реалізовано перевантажені конструктори з ланцюговим викликом `: this()`, що дозволило уникнути дублювання коду ініціалізації. Продемонстровано життєвий цикл об'єкта: створення через різні конструктори, використання методів та примусове знищення об'єктів через `GC.Collect()` і `GC.WaitForPendingFinalizers()`, після чого в консолі з'явились повідомлення з деструкторів.
